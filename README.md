# NAKUL SOLAR SYSTEM
### Interactive Astronomical Visualization

A real-time, browser-native 3D visualization of the Solar System built with
WebGL, Three.js and custom GLSL. Runs entirely client-side — no backend, no
database, no API keys, and no downloaded imagery.

---

## Quick start

### Local
Any static file server works. Module workers and ES modules require `http(s)`
(not `file://`):

```bash
npx serve .
# or
python3 -m http.server 8080
