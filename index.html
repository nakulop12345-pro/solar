NAKUL SOLAR SYSTEM

Interactive Astronomical Visualization · v1.0

Real-time 3D visualization of the Solar System. All planetary surfaces, ring systems, nebulae and star fields are generated procedurally in the browser using seeded value-noise fields — no third-party imagery is downloaded, so the project is fully offline-capable and free of licensing ambiguity.

Orbital & physical data

  • E. M. Standish, Keplerian Elements for Approximate Positions of the Major Planets — NASA/JPL Solar System Dynamics. Public domain.
  • NASA Planetary Fact Sheets (NSSDCA) — public domain.
  • JPL Planetary Satellite Physical Parameters — public domain.
  • JPL Horizons / NAIF SPICE documentation — public domain.

Software

  • Inter & JetBrains Mono typefaces — SIL Open Font License 1.1.

Approximations

  • Planet positions use first-order Keplerian elements (valid ≈1800–2050 AD).
  • Satellite orbits are modelled as circles in the parent's equatorial plane.
  • Body radii and satellite orbit radii are visually compressed — see README.md.
  • Times are UTC; elements are referenced to TDB. The difference (< 2 min) is not modelled.
